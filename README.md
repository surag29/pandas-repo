# Pandas Repository - Data Manipulation & Analysis

A comprehensive collection of Pandas practice exercises and real-world data manipulation techniques demonstrating proficiency in data cleaning, transformation, and exploratory data analysis (EDA).

## Overview

This repository showcases practical applications of the Python Pandas library, a fundamental tool for data analysts. It contains structured exercises and projects covering core data manipulation skills essential for entry-level data analyst positions.

## 📊 Contents

### Core Concepts Covered
- **DataFrames & Series**: Creating and manipulating tabular data structures
- **Data Cleaning**: Handling missing values, duplicates, and data type conversions
- **Data Transformation**: Reshaping, merging, and aggregating datasets
- **Exploratory Data Analysis (EDA)**: Statistical analysis and data profiling
- **GroupBy Operations**: Segmentation and aggregation by multiple dimensions
- **Time Series Analysis**: Handling temporal data and resampling
- **Data Visualization Integration**: Preparing data for visualization with Matplotlib/Seaborn

## 📖 How to Use

1. **Clone the repository**:
   ```bash
   git clone https://github.com/surag29/pandas-repo.git
   cd pandas-repo
   ```

2. **Install dependencies**:
   ```bash
   pip install pandas numpy jupyter matplotlib seaborn
   ```

3. **Launch Jupyter Notebook**:
   ```bash
   jupyter notebook
   ```

4. **Explore notebooks**: Open any `.ipynb` file to view exercises and solutions
